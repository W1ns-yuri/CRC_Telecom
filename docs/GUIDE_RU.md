# Как устроен проект (шпаргалка для Юрия)

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000 → редирект на /fr
npm run build      # продакшен-сборка
npm run typecheck  # проверка типов
```

Переменные окружения — в `.env.example` (скопируй в `.env.local`). Без ключей всё работает: письма и сохранение заявок просто пишутся в консоль.

## Где что лежит

```
src/
  app/[locale]/        страницы. [locale] = fr или en
    page.tsx           главная
    services/[slug]/   шаблон страницы услуги (один на все 9)
    industries/ areas/ отрасли и регионы (тоже шаблоны)
    contact/ support/  формы
    legal/[slug]/      юридические страницы
  app/api/forms/       приём форм: валидация → капча → письмо → сохранение
  app/api/consent/     журнал согласий на cookie
  content/             ВЕСЬ текст сайта (FR + EN) — услуги, отрасли, регионы, юр. тексты
  messages/fr.json     короткие строки интерфейса (кнопки, заголовки)
  components/          шапка, футер, формы, карта, анимации
  i18n/routing.ts      языки и локализованные адреса (/fr/secteurs ↔ /en/industries)
  middleware.ts        выбор языка, Квебек → французский
```

## Главные идеи, которые стоит понимать

1. **Серверные и клиентские компоненты.** По умолчанию компонент серверный: рендерится в HTML на сервере, JS в браузер не попадает. `"use client"` вверху файла — только там, где нужен браузер: состояние, клики, canvas, анимации (Header, Forms, CoverageMap, WhyPinned…).
2. **Контент отделён от вёрстки.** Страница услуги одна (`services/[slug]/page.tsx`), а 9 услуг — это 9 объектов в `content/services.ts`. Позже эти объекты переедут в Sanity, вёрстка не изменится.
3. **Два языка = одни данные.** У каждого текста форма `{ fr: "...", en: "..." }`, функция `tr(value, locale)` берёт нужный язык.
4. **Статическая генерация.** `generateStaticParams` говорит Next.js заранее собрать все страницы (`/fr/services/...`, `/en/services/...`). Поэтому сайт быстрый.
5. **Валидация в двух местах.** Схема Zod в `lib/forms.ts` проверяет форму и в браузере (быстрая подсказка), и на сервере (защита — браузеру верить нельзя).
6. **Анимации не ломают доступность.** Всё движение выключается, если в системе включено «уменьшить движение». Контент виден и без JS.

## Проверь себя

- Как добавить 10-ю услугу? (Ответ: добавить объект в `content/services.ts` — страница, меню, футер, sitemap и форма подхватят её сами.)
- Почему `Header.tsx` клиентский, а `Footer.tsx` серверный?
- Что произойдёт с формой, если не задан `RESEND_API_KEY`?
